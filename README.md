## 🔬 Research Experience

### Trust.EO – Examining Trustworthiness in Earth Observation Vision Models

**Accepted at ICMLDE 2026 | Paper ID: 445**

Exploring the gap between predictive accuracy and broader evaluation measures in Earth Observation vision models.

- Evaluated Earth Observation models including Prithvi-100M, ResNet-18, and ViT-Base.
- Investigated model reliability, explainability, and provenance.
- Developed the ASCOPE provenance framework to examine trust-related dimensions.
- Explored the limitations of relying exclusively on predictive accuracy when evaluating remote-sensing models.

### Aditya-L1 Solar Flare Detection & Forecasting

Working with solar observation data from ISRO's Aditya-L1 mission, exploring ML-based solar flare detection and forecasting.

- Working with SoLEXS and HEL1OS observational data alongside GOES labels.
- Exploring time-series modelling and multimodal solar observation data.
- Investigating early-warning systems for solar flare events.

## 💻 Featured Projects

### FinGuard.io – AI-Powered Aquaculture Intelligence

An AI-driven aquaculture platform designed to help fish farmers monitor pond health, detect diseases, and make informed decisions.

- AI-powered fish disease detection using Gemini vision capabilities.
- Pond monitoring through important water-quality parameters.
- Fish-specific health and mineral requirements.
- Community-based early-warning system for identifying emerging disease patterns across farms.

### OptiKinesis – Assistive Technology Through AI

An accessibility-focused platform designed to help individuals with motor disabilities interact with computers.

- Real-time eye-tracking cursor control.
- AI-powered predictive keyboard using Gemini.
- Voice assistant and hands-free interaction.
- Emergency caregiver assistance.
- Breathing analysis integration through Presage SmartSpectra.
- Twilio and ElevenLabs integration for voice-based communication.

### TalkIt – Voice-First Desktop Copilot

A Windows-first voice-powered desktop assistant focused on making computer interaction faster and more natural.

- Voice-driven text generation and execution workflows.
- AI-powered prompt building.
- Desktop productivity and automation.
- Developer-oriented workflow exploration.

### SoundSeparation – Deep Learning for Audio Source Separation

Experimenting with deep learning architectures for separating multiple voices from mixed audio.

- Implemented Conv-TasNet for audio source separation.
- Explored Mamba-based architectures for time-series modelling.
- Worked on neural approaches to multi-speaker audio separation.

### AI Digital Twin – RAG-Based Knowledge Assistant

An AI-powered digital twin built using retrieval-augmented generation.

- Built using FastAPI, LangGraph, ChromaDB, and Gemini 2.5 Flash.
- Implemented semantic and hybrid retrieval.
- Explored BM25, vector search, embeddings, and reranking.
- Designed a conversational knowledge retrieval pipeline.

### GestureCTRL – Real-Time Gesture Recognition & Automation

A computer vision-based system enabling hands-free computer interaction.

- Real-time hand gesture recognition using MediaPipe.
- KNN-based gesture classification.
- React and Vite frontend.
- Node.js, Express, and WebSocket backend.
- Desktop automation using PyAutoGUI.
